# Urban Traffic Multi-Object Tracking

## Project Overview

This project demonstrates practical video annotation and multi-object tracking using CVAT (Computer Vision Annotation Tool).

The objective was to annotate an urban traffic video by identifying different object categories, creating bounding boxes and assigning consistent tracking IDs to individual objects across video frames.

## Project Objectives

- Identify and classify objects in urban traffic footage.
- Create accurate bounding box annotations.
- Assign unique tracking IDs to individual objects.
- Maintain consistent object identities across video frames.
- Export structured annotations for computer vision applications.

## Tools Used

- CVAT – Video annotation and object tracking.
- Computer Vision – Object identification and classification.

## Annotation Methodology

1. Uploaded the source video into CVAT.
2. Created the required object labels.
3. Used bounding boxes to identify objects.
4. Assigned tracking IDs to individual objects.
5. Followed objects across consecutive video frames.
6. Reviewed annotations for consistency and accuracy.
7. Exported the completed annotations in CVAT for video format.
